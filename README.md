# Vrinda Store Sales Analysis

Guided practice project (Oct 2024), built by following Rishabh Mishra's YouTube tutorial.

**What it is:** an annual sales report for a clothing store in Excel: cleaning the raw data, pivot tables, and a one-page dashboard (sales by month, by state, by channel, by age group and gender).

**Files:** `Raw data.xlsx` (the data), `Vrinda Store Sales Analysis.xlsx` (the workbook and dashboard), a screenshot.

**What I learned:** cleaning data in Excel, pivot tables and slicers, and laying out a dashboard so the key numbers are read first.
