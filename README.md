# Vrinda Store Sales Analysis

> Guided practice project (Oct–Nov 2024), built by following Rishabh Mishra's YouTube tutorial.

An Excel report on one year of sales for a clothing store, "Vrinda Store".

## The data
About 31,000 orders: date, customer gender and age, state, sales channel, category, quantity, amount and order status.

## What I did
- Cleaned the data and added the columns the report needed, like age group and month.
- Built 6 pivot tables and 12 charts.
- Made a one-page "Report 2024" dashboard with a slicer.

## What the dashboard shows
- Orders and sales by month
- Sales by men and women
- Order status
- The top 5 states by sales
- Orders by age group and gender
- Orders by sales channel

## Tools
Excel, pivot tables, charts, slicers.

## Files
- `Raw data.xlsx`: the raw data
- `Vrinda Store Sales Analysis.xlsx`: the workbook and the dashboard
- a screenshot of the dashboard

## What I learned
Cleaning data in Excel, building pivot tables, and laying out a dashboard so the main numbers are read first.
